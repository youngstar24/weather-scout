## 汇总

- **通过率**：10/10 场景通过（含 2 项带轻微注意事项）；未测项：无。

### 发现的问题（按严重度）

**阻塞**：无。

**一般**：无。

**轻微**：
1. **N1（S2）**：多选景观时，除第一个选中的 chip 外，其余已选 chip 缺少 `on` 选中高亮样式，仅靠浏览器焦点框和地图图例「已选：…」文字辨识选中态，易造成困惑。
2. **N2（S1）**：桌面端详情抽屉打开时，地图版权层（leaflet attribution「© 高德地图…数据 © Open-Meteo」）叠加显示在抽屉底部按钮行上方，部分遮挡「用当前条件订阅此地」按钮，z-index 层级关系欠妥。
3. **N3（S1）**：PRD 验收口径「详情含四个外链按钮」与实际不符——抽屉底部为 3 个外链（高德导航/百度地图/攻略门票）+ 1 个站内订阅按钮；若验收口径按「外链」严格计数，则差 1 个（无第 4 个外链，如 Open-Meteo 仪表盘之类）。
4. **N4（S7）**：数据说明弹窗对 Open-Meteo 仅注明「免费非商业、无需 Key」及商用需评估授权，未写明具体数据许可名称（如 CC-BY 4.0），许可声明不够明确。

**提示（不计为缺陷）**：
5. **N5（S9）**：刷新成功路径的 toast 未能在目视截图中捕获（成功仅通过数据时间戳 14:15→14:25 UTC 变化确认）；失败路径 toast 已有清晰截图证据。toast 显示时长较短（约 2 秒），建议延长或提供持久状态提示。

### 测试操作备注

- S9 中依任务书执行了「reload + 注入 error 监听」诊断步骤；S3 中按任务书使用 evaluate 设置滑块值一次，其余全部交互（点击、键盘、下拉、勾选）均为真实 GUI 操作。
- 刷新功能连续点击触发的 Open-Meteo HTTP 429 为外部服务限流，非被测站点缺陷；应用对此的兜底表现（toast + 保留旧数据）符合 PRD 健壮性要求。
